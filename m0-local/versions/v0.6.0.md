# 0.6.0 源码版本

记录日期：2026-10-23。类型：**source-release（源码发布）**。标签：`v0.6.0`。

本版本开始保存当前工程的完整源码快照。标签对应此版本的代码和依赖清单；安装依赖并准备本地恢复组件后按项目说明启动。个人配置、会话、登录状态与运行缓存不属于源码发布。

## 本版变化

- Design 默认在独立的 Figma 桌面容器中打开官方编辑器，由 Figma 提供画布、矢量编辑和云端协作。
- Plugin Bridge 使用限时配对码，命令绑定项目、文件、插件会话、选区与节点；以实际回执判断执行结果。
- 本地助手、多 Agent 和恢复的 OpenCode 通过相同桥接工具读取、导出、创建和修改节点；AI Figma 写入默认关闭。
- Figma 导出接入恢复的 KRN 转换器，复杂外观可保留真实导出图片并附降级说明。
- 保留原 M0 工作台、项目与会话、代码编辑器、终端、扩展市场，以及已有独立画布与设计数据。

## 验证和边界

[整合说明](../docs/本地整合-0.6.0.md)与[可上传的验收摘要](evidence/v0.6.0.json)记录 122 项 Node 回归、17 项宿主策略与生命周期检查及 16 项独立桌面检查通过，另有原扩展市场、导航和生成器回归。

本地原始来源为 `diagnostics/figma-all-node-tests.log`、`diagnostics/figma-host-policy.log` 和 `diagnostics/figma-release-summary.json`，不上传仓库。验收摘要保留来源文件的字节数和 SHA-256，只发布白名单检查结果、计数与限制，不包含原始诊断、个人配置、登录资料或会话。

桌面检查实际打开官方登录页。插件操作使用真实插件代码和 HTTP 队列/回执，但节点由明确的 Plugin API VM 测试场景提供；没有据此宣称用户账号的云端文件读写、真实协作或外部模型完成端到端验收。登录后需在目标文件运行插件并配对，操作步骤见[真实 Figma 接入指南](../docs/真实Figma接入.md)。

恢复构建、补写适配和原始源码具有不同来源；本工程不保证与原软件二进制或全部云端功能等同。版本记录见[总表](index.json)，后续发布按[版本发布说明](../docs/版本发布.md)保存准确源码。

## GitHub 发布与运行包

本版新增逐版 Git 标签与 Release 发布流程。恢复运行组件以同版本附件保存，归档共 6,286 个文件、33 个依赖，清理派生副本内的旧凭据和无用 postinstall，原恢复证据保持原样。独立源码副本加运行包完成 127 项 Node、17 项宿主、3 项市场及 3 项导航检查，另通过原生成器与旧画布检查；npm 依赖复用已安装的同版依赖。详情见[发布验收摘要](evidence/github-publication-v0.6.0.json)与[运行包说明](../docs/GitHub运行包.md)。
