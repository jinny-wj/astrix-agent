# 0.6.1：合入 Astrix 与发布兼容

记录日期：2026-10-23。类型：**source-release（源码发布）**。标签：`m0/v0.6.1`。

M0 的正式仓库位置改为 `jinny-wj/astrix-agent` 的 `m0-local/`。本版整理同仓库目录、历史和发布方式；UI、真实 Figma、Plugin Bridge、Agent、原编辑器与终端的功能没有改变。

## 合入与历史

- 0.1.0～0.5.0 继续明确为 `documentation-only`，导入标签为 `m0/history/v0.x.0`，没有补造旧版源码。
- 原 0.6.0 应用源码导入为 `m0/v0.6.0`，既有标签不移动；本次兼容调整保存为新的 `m0/v0.6.1`。
- [历史导入映射](../docs/历史导入映射.json)记录六个阶段的原始引用、原始提交、导入引用与导入提交，并列出按仓库规则排除的生成分发文件数。
- 未来 M0 正式版本使用 `m0/v版本号` 命名空间，不复用 Astrix 的普通版本标签、预览标签或 latest 发布入口。

## 源码与运行资源

公开 Git 和 `m0/v0.6.1` Release 保存应用源码与文档。`public/`、`plugins/recovered/`、额外静态资源、图标等生成分发物，以及恢复的原引擎组件，按仓库规则留在 Git 之外；受限草稿 `m0-runtime/v0.6.1` 提供对应资源。访问限制和具体文件以[运行包说明](../docs/GitHub运行包.md)为准。

新克隆后在 `astrix-agent/m0-local` 安装依赖和启动；恢复引擎包解压后的目录为 `astrix-agent/M0-AI-recovered`。资源准备后再运行测试。公开源码包本身不等于包含全部运行资源的安装器。

## 验证与限制

本版记录已核对七个版本条目、六阶段历史映射、M0 标签命名空间和文档链接。它不把旧私有仓库的测试次数计为新一轮功能验收；合入后的实际测试以本版发布执行结果为准。

[旧 0.6.0 发布摘要](evidence/github-publication-v0.6.0.json)保留原私有仓库来源字段。该记录只证明当时的受限发布与测试，不代表当前公开 Release 包含旧运行附件。真实 Figma 账号文件写入、云端协作和外部模型仍遵循 [0.6.0 的验收边界](v0.6.0.md)，本次目录与发布调整没有扩大这些结论。

逐版流程见[版本发布说明](../docs/版本发布.md)，当前版本总表见 [index.json](index.json)。

独立源码副本仅使用本版两个资源包还原后，通过 143 项 Node 回归、17 项 Figma 宿主、3 项市场和 3 项导航检查，以及生成器和旧画布检查；发布器另通过 14 项专门测试。npm 依赖复用已安装的同版依赖。详情见[本版验收摘要](evidence/v0.6.1.json)。正式发布命令还会执行当前源码的发布门禁。
