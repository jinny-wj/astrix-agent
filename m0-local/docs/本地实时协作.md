# 本地实时协作

此功能为本地新增的操作协作层，使用当前项目的 `canvas.json`、服务端串行事务、SSE 和 HTTP 操作提交。没有复用原账号、原协作凭据或企业同步服务，也不声称实现了 CRDT。

## 使用范围

- 同一项目可由多个窗口或浏览器同时编辑，显示参与者、世界坐标光标、选中图层、页面位置和加入/离开状态。
- 默认只有本机服务。主持人可以显式开启独立的局域网入口，给其他电脑发送编辑或只读邀请。
- 编辑邀请可提交授权画布操作；只读邀请只允许接收状态和发送光标/选区。邀请撤销或到期会结束已经打开的事件流，并拒绝后续读写与重新加入。
- 每个会话固定项目和真实工作区。切换全局项目不会让原会话向另一个项目写入。
- SSE 断线重连会重放有限历史；历史已淘汰则发送完整快照。有效会话中未确认操作可用相同 `mutationId` 重试，不会重复应用。快照中的私有确认记录可以恢复已经保存、但 HTTP 确认丢失的操作。

局域网入口是明确开启的 HTTP 服务。它只提供公开画布静态资源和邀请授权后的协作接口；主应用的本地文件、模型配置、版本管理和其他 API 不在该入口开放。关闭入口后连接结束，原本机服务仍使用回环地址。跨电脑邀请应在可信网络使用；当前没有公网中继或 TLS 配置。

## 合并与冲突规则

共享模块为 `canvas/collab-model.mjs`：

```js
const ops = diffDocuments(before, after);
const {document, conflicts, applied} = applyOperations(current, ops);
```

画布按稳定 ID 转为文档、页面、节点和组件实体；操作携带修改前后的值，服务端在画布原有事务锁内对比并原子保存：

- 不同节点、同一节点不同字段的并发修改可以合并。
- `layout` 和 `prototype` 的子字段可分别合并；路径、渐变等复杂对象作为一个字段比较。
- 同一字段已被别人改成不同值时，整批返回 HTTP 409。不会偷偷采用最后写入，也不会部分写入其他字段。返回当前文档和冲突位置，客户端保留未同步草稿，提供导出或重新载入。
- 同一页面或父节点下的独立插入可合并，使用稳定 ID 和存活的右侧锚点放置；保留其他成员新增的节点，不复活已经删除的节点。
- 显式重排采用严格比较；删除实体检查完整旧值，删除子树也检查各子节点。另一成员已修改子节点时，不会被旧删除操作吞掉。
- 重建整棵树会检查缺失节点、重复父节点和循环。结构不一致时整批拒绝。
- `activePageId` 是窗口自己的视图状态，不参加协作修改；当前页面通过 presence 发送，不会因另一成员切页而被强制切页。

正常保存、版本恢复和套用模板使用同一个 canvas 保存入口并立即广播。外部编辑器直接改文件由活动房间轮询兜底发现；文档删除或变为无效 JSON 会通知连接异常，服务端不会为了应用旧草稿自动重建被外部删除的文件。有效文档恢复后发送完整快照。

## 服务接口

`server/canvas-collaboration.mjs` 导出：

```js
const collaboration = createCanvasCollaboration({
  dataDir,
  resolveWorkspace: canvas.target,
  readCanvas: canvas.read,
  transactCanvas: canvas.transact,
  subscribeCanvas: canvas.subscribe,
});
await collaboration.handle(req, res, url, parsedBody);
await collaboration.close();
```

本机入口前缀为 `/__local/collaboration/`：

| 路由 | 方法与作用 |
| --- | --- |
| `capabilities` | GET，协议能力和限制 |
| `rooms` | POST，以指定项目创建房间；仅空画布可按 `expectedRevision:null` 初始化草稿，已有文档不会被传入草稿覆盖 |
| `join` | POST，本机主持人按项目加入；邀请成员使用 `invite`；有效 `sessionToken` 可恢复既有会话 |
| `state` | GET，带 `sessionToken`，返回当前快照 |
| `events` | GET SSE，带 `sessionToken` 和可选 `since`；支持 `Last-Event-ID` |
| `ops` | POST，`{sessionToken, mutationId, ops, baseRevision?}` |
| `presence` | POST，`{sessionToken, pageId, pointer, selectedIds}`；也接受 `cursor/selection` 同义字段 |
| `leave` | POST，立即离开当前会话 |
| `invites` | 主持人 POST 创建 `editor/viewer` 邀请，GET 查看本房间邀请记录 |
| `invites/<id>` | 主持人 DELETE 撤销，并立即断开由该邀请建立的会话 |
| `gateway` | 仅本机主持人 GET 状态，POST `{enabled:true/false}` 开关独立局域网入口 |

加入响应包含 `roomId`、`epoch`、`clientId`、`role`、`sessionToken`、`document`、`revision`、`seq`、`workspaceKey`、`projectId`、`participants` 和 `eventsUrl`。显示名不是认证身份；会话令牌才是权限依据。浏览器复制标签页导致 `clientId` 重复时，会分配新的显示 ID。

`join`、`state`、操作响应与 SSE 快照包含 `acknowledgedMutationIds`，只列当前会话自身最近 256 个已确认操作。客户端先移除这些待确认操作，再合并剩余草稿；即使历史已淘汰、其他成员后来又修改同一字段，也不会把早已保存的操作误判为未同步冲突。确认记录不包含其他会话的私有列表。

SSE 统一发送 JSON `data`，类型包括 `snapshot`、`document`、`presence`、`joined`、`left`、`revoked`、`ready`、`sync-error`。文档增量事件携带 `baseRevision`、`revision`、`ops` 和序号；客户端应先检查基础修订号，不能连续应用时重新取 `state`。`Last-Event-ID` 优先于 URL 中最初的 `since`。广播操作由真实保存前后的规范文档重新计算，包含并发序列合并和校验器对引用的修正，不盲目转发原请求。

房间每次服务实例创建都会生成新 `epoch`。客户端通过完整快照接受新实例的较低序号，并保留待同步草稿重新合并；旧实例迟到的 HTTP 确认、事件或快照不能回退新状态。

权限错误返回 403；冲突返回 409 和 `{current:{document,revision,seq},conflicts}`。局域网入口不开放 `rooms`、`invites`、`gateway` 等管理接口，即使请求带主持人令牌也不开放。

## 持久化与限制

画布内容仍原子写入项目 `canvas.json`。邀请只把令牌的 SHA-256、角色、项目、真实目录指纹、有效期及撤销状态保存到 `.local-data/canvas-collaboration/invites.json`；临时文件原子替换，目录与文件限制为本地普通文件。原始短邀请只在创建时返回；会话令牌、在线状态和事件日志不写盘。

服务重启后应重新使用有效邀请加入；旧会话令牌与确认记录失效。重新加入后无法证明已保存的旧操作，遇到同字段冲突会保留草稿供用户处理，不无声覆盖。默认事件历史最多 256 条或 8 MB；房间最多 32 名参与者；邀请有效期为 1 分钟至 7 天，同一房间最多 30 个有效邀请。单次操作最多 10000 项，操作 JSON 上限 4.5 MB。慢事件流的缓冲过大时会关闭连接，客户端可重新同步。

## 验证

`node --test canvas/collaboration-state.test.mjs test/canvas-collaboration.test.mjs` 当前 24 项测试通过，包括：同页并发新增、异字段合并、同字段整批冲突、子树删除保护、只读拒写、重试幂等、断流重放、历史淘汰后快照、丢失 HTTP 确认后的私有回执恢复、服务重启序号归零、旧响应不回退、自己的撤销保留其他成员修改、恢复与外部编辑广播、外部删除保护、邀请撤销/到期、复制标签页身份区分、项目切换隔离，以及局域网路由和跨站请求边界。双窗口真实界面联调由主任务另行记录。
