# 版本记录

本工程保存了 0.1.0～0.6.0 的阶段记录。**0.1.0～0.5.0 未保留完整源码快照，只能追溯当时的文档和验证证据；当前完整源码从 0.6.0 开始保存。** 不能通过检出历史记录标签取得对应旧版软件。

历史阶段使用 `history/v0.x.0` 标签，正式源码版本使用 `v0.x.0` 标签。机器可读清单见 [versions/index.json](versions/index.json)，流程见 [版本发布说明](docs/版本发布.md)。以下验证数量为各阶段留下的结果，不代表在当前版本重新运行旧版测试。

## 0.6.0 — 2026-10-23

**源码版本：`v0.6.0`。** [详细版本记录](versions/v0.6.0.md)

- Design 默认打开真实 Figma，通过独立桌面容器保留官方编辑、矢量和云端协作能力。
- 接入配对 Plugin Bridge，传递选区、受控节点修改、导出和实际执行回执。
- 本地助手、多 Agent 与恢复的 OpenCode 共用桥接工具；AI Figma 写入默认关闭。
- 真实 Figma 导出可接入恢复的 KRN 转换器，保留原工作台、代码编辑器、终端和扩展市场。
- 阶段验证记录为 122 项 Node 回归、17 项宿主策略与生命周期检查、16 项独立桌面检查。插件节点操作使用明确的 Plugin API VM 测试场景；尚未用用户账号完成真实云端文件写入验收。

## 0.5.0 — 2026-10-23

**仅历史文档：`history/v0.5.0`；无完整源码快照。** [详细版本记录](versions/v0.5.0.md)

- 本地独立画布增加钢笔与贝塞尔编辑、路径布尔运算、旋转翻转、渐变及 SVG 导入导出。
- 增加按属性合并的实时协作、光标与选区、本人操作撤销、独立协作窗口及可选局域网入口。
- 原 KRN 代码生成保留实际矢量素材；旧画布能力在 0.6.0 中保留，但不再作为默认 Design 入口。
- 阶段验证记录为 95 项 Node 检查、6 项附加策略/导航检查，以及 59 项画布和多窗口界面检查。

## 0.4.0 — 2026-10-23

**仅历史文档：`history/v0.4.0`；无完整源码快照。** [详细版本记录](versions/v0.4.0.md)

- 本地独立画布增加多页面、多选、对齐分布、自动布局、组件、文字与图片。
- 增加本地设计版本、评论、模板、固定内容分享及可点击原型导出。
- 原 KSCode 扩展市场接入 Open VSX，保留本地 VSIX 安装。
- 阶段验证记录为 48 项 Node 集成检查、3 项市场策略检查、3 项桌面导航检查，并保存多组实际界面验收记录。

## 0.3.0 — 2026-10-23

**仅历史文档：`history/v0.3.0`；无完整源码快照。** [详细版本记录](versions/v0.3.0.md)

- 增加本地基础画布、项目保存、导入导出及原 KRN 代码生成入口。
- 接入恢复的 LangGraph 与独立角色调度，支持规划、依赖、执行、复核、进度与停止。
- 恢复原 xterm、PTY 终端、扩展宿主、VSIX 安装、语言服务与文件监视。
- 阶段验证记录为 38 项 Node 集成检查；另有编辑器、终端/扩展、画布和工作流界面验收。

## 0.2.0 — 2026-10-23

**仅历史文档：`history/v0.2.0`；无完整源码快照。** [详细版本记录](versions/v0.2.0.md)

## 0.1.0 — 2026-10-23
