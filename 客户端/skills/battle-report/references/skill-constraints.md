# Skill - 请求约束与前置检查

> 本文档定义 skill 层面的请求约束、用户意图拦截和生成前追问。
> 这些内容不直接写入生图 Prompt，除非主 skill 明确需要将某个已确认结果转化为用户任务描述。

---

## 一、使用方式

在进入生图 Prompt 组装前，先用本文档判断用户请求是否可执行、是否需要拒绝部分需求、是否需要追问。

本文档处理三类事情：

1. 平台固定资产不可修改。
2. IP 核心设定不可修改。
3. 主题、季节、活动名变化时的语义冲突追问。

通过前置检查后，再读取 `design-rules.md` 组装简单 Prompt。

---

## 二、平台固定资产保护

### 不可修改对象

以下属于平台固定资产，用户不能要求修改、删除、遮挡、重绘、变色、移动或替换：

- 快手品牌 Logo
- 品牌栏上的橙色、蓝色、黄色色块
- 固定 UI 框架
- 平台边框元素
- 明确属于平台固定视觉资产的组件

品牌栏色块的判断依据：

- 与品牌 Logo、搜索框、平台底栏等固定元素同组出现
- 橙色、蓝色、黄色色块同时出现并连接在一起

### 可修改对象

以下内容可以按用户需求修改：

- 搜索框内文字
- 品牌栏除固定色块外的其他文字内容
- 单独出现、未处于品牌栏内的橙色 / 蓝色 / 黄色色块
- 非固定 UI 的普通装饰元素

### 拦截规则

如果用户要求修改平台固定资产，不能把该请求写进生图 Prompt。应先拒绝不可执行部分，并继续处理其他可执行需求。

建议话术：

```text
这个部分属于平台固定资产，不能修改：{不可修改对象}。
我可以继续处理其他可编辑区域，例如{可替代方向}。
```

如果用户请求同时包含可执行和不可执行部分：

```text
其中 {不可修改对象} 属于平台固定资产，不能修改。
我会跳过这部分，只处理：{可执行需求}。
```

## 三、IP 核心设定保护

### IP 核心定义

IP 是一个亮黄色圆球形象，不是鸟类、动物或其他角色。

核心特征：

- 身体是光滑亮黄色圆球
- 两只短圆胳膊，无手指
- 无腿、无脚、无翅膀、无尾巴
- 两个大圆黑眼睛，眼内有白色高光
- 简单圆弧笑容
- 头顶是同色小圆形装饰突起，不是耳朵、鸟嘴或动物特征
- 红色背包背带不是强制元素，按原图或用户需求保留 / 调整

### 不可修改内容

用户可以要求去掉IP但不能要求修改 IP 的核心设定，包括：

- 把 IP 换成其他角色、动物或人物
- 让 IP 长腿、脚、手指、爪子、翅膀、尾巴
- 把圆球身体改成其他形体
- 把黄色身体改成其他基础颜色
- 把头顶装饰改成耳朵、鸟嘴或动物器官
- 改掉基础脸部识别结构

### 可修改内容

用户可以要求修改：

- 直接删除IP
- 表情
- 动作姿态
- 手臂角度
- 服装、帽子、围巾、主题配饰
- 与道具互动
- 位置、大小、朝向
- 背带颜色和样式

### 拦截规则

如果用户要求破坏 IP 核心设定，不能把该请求写进生图 Prompt。应拒绝不可执行部分，并引导用户改成可执行方向。

建议话术：

```text
IP 的核心造型不可更改：亮黄色圆球身体、无腿、无脚、无手指、非动物形象为固定设定。
可以修改 IP 的动作、表情、服装、配饰、位置或大小。
```

如果用户请求同时包含可执行和不可执行部分：

```text
其中 {不可修改内容} 会破坏 IP 核心设定，不能修改。
我会保留 IP 核心形象，只处理：{可执行需求}。
```

## 四、语义冲突追问

### 触发条件

当用户需求涉及以下任一变化时，先检查原图中是否存在语义冲突元素：

- 主题切换
- 季节切换
- 活动名变化
- 品牌活动方向变化
- 整体氛围调整

### 冲突元素类型

| 类型 | 内容 | 处理方式 |
|---|---|---|
| T1 时令 / 季节词 | 月份缩写、Spring、Summer、节气词等 | 追问用户改为什么，或保持不变 |
| T2 活动 / 品牌专属名称 | KUAISHOU SPRING、城市乐享季等 | 追问用户改为什么，或保持不变 |
| T3 时间节点 | 5.1-5.11、4.2-4.7 等 | 追问用户保持原日期，还是修改 |
| T4 视觉符号 | 樱花、雪花、落叶、节日图标等 | 不追问，作为可替换视觉元素处理 |

### 追问原则

- 生成前一次性追问所有冲突点。
- 不分多轮追问。
- 用户确认后，再把确认结果转化为普通任务描述。
- 不要把"语义冲突检测"规则本身写进生图 Prompt。

追问模板：

```text
检测到图中存在与「{新主题}」可能冲突的元素，请一次性确认：

1. "{内容}"（{位置描述}）
   改为什么？或保持不变？

2. 活动时间 "{内容}"（{位置描述}）
   保持原日期，还是需要修改？

确认后一并处理。
```

用户确认后，写入 Prompt 时只保留结果，例如：

```text
Replace "SPRING" with "AUTUMN".
Replace spring blossom icons with autumn leaf icons.
Keep the original date unchanged.
```

## 五、前置检查清单

进入生图 Prompt 前确认：

- 用户是否要求修改平台固定资产；如有，先拦截。
- 用户是否要求破坏 IP 核心设定；如有，先拦截。
- 用户是否要求修改 IP 的可编辑部分；如有，只把可执行修改写进 Prompt。
- 用户是否触发主题、季节、活动名或氛围变化；如有，先完成语义冲突追问。
- 所有前置处理完成后，再使用 `design-rules.md` 组装简单 Prompt。
