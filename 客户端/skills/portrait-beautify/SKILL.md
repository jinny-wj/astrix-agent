# 主播照片一键美化

把低质量主播原图做成可交付人像：抠图、修图、保脸，必要时再套盛典/战报模板。

## 目标

- 3000 张海报从约 60 人日压到 2–3 天量级。
- 原图可以是自拍、全身、复杂背景、低光、甚至黑白。
- **脸必须是本人**。可以换衣服、光影、背景，不能整容式换脸。

## 输入

- `photos`: 主播原图，本地文件 / 聊天图片 / 表格里的缩略图。
- `sheet`（可选）: Excel/Doc，含身份、姓名、标题、标签。
- `template`（可选）: 盛典主视觉或海报母版。没有模板时只交付美化后的人像。

## 执行顺序

1. **识别人像**：找到脸和上半身；全身或手持道具时裁到腰上肖像。
2. **抠图**：干净去底，头发和手部边缘单独检查。
3. **修图（保脸）**：磨皮、统一暖金光、提高清晰度；五官结构、脸型、痣、发型轮廓锁定。
4. **套版（有模板才做）**：人物居中，标题/标签/Logo 按母版排，不重绘品牌字。
5. **质检**：脸不像本人、抠图破边、文字糊、衣服穿帮的标红，留给人工改。

## 保脸硬规则

- 禁止换脸、换年龄、换性别、整容式五官。
- 衣服、背景、光影、清晰度可以改。
- 极限原图（全身、抱玩偶、户外、黑白）先保脸再处理构图。
- 交付前用一句话说明：改了什么、脸有没有被动。

## 用户可见流程

1. 请用户上传照片；有表格就一并收。
2. 先出 1–2 张小样，确认「还是本人」后再批量。
3. 批量结果按「通过 / 需人工」分组。
4. 通过的可以继续进「人物战报」或「资源位延展」。

## 禁止

- 不要向用户讲模型名、API、prompt 结构。
- 不要在未确认保脸前对全量照片出成片。
