# 图片、资源位与 H5 调整

在 Figma 中运行当前版本的 Design Studio Bridge，选中目标图层，再在 Agent 输入框上方选择「图片调整」「资源位尺寸」或「H5 调整」。设置参数后点击「加入输入框」，检查指令并发送。多选时指令应用于全部选中图层。

也可以直接输入：

| 对象 | 指令示例 | 结果 |
| --- | --- | --- |
| 含图片填充的图层 | `图片适应` / `图片填充` | 完整显示原图 / 铺满图层，铺满可能裁切 |
| 含图片填充的图层 | `图片曝光设为 15%；图片饱和度设为 -20%` | 修改图片调色，保留原图和其他填充 |
| 资源位画板 | `尺寸改为 直播广场banner` | 584×160；也支持直播封面 720×1280、活动弹窗 840×1120、H5首屏 375×812 |
| 资源位画板 | `尺寸改为 900×1600` | 使用指定尺寸，内容按原有约束变化 |
| H5 文本图层 | `字号设为 24px；行高设为 36px` | 设置文字大小与像素行高 |
| 支持圆角的图层 | `圆角设为 16px` | 设置统一圆角 |
| 水平/垂直自动布局容器 | `间距设为 12px；内边距设为 24px` | 设置固定间距与四边内边距 |
| 水平/垂直自动布局容器 | `上内边距设为 32px` | 只调整上内边距 |

图片曝光、对比度、饱和度、色温使用 -100% 至 100% 的绝对值，0% 为中性。图片操作修改选中节点自身的图片填充，不会递归寻找子节点，不涉及生成、抠图或换脸。

H5 指 Figma 中的设计稿。这些操作不会修改或发布已有 HTML 页面。资源位尺寸调整也不会自动重排全部子图层、生成多套构图或导出压缩文件；请检查主体裁切、文案和安全区。使用自动间距的容器需要先在 Figma 中切换为固定间距。

执行锁定目标文件、会话与选区版本；混选不兼容图层会在预检时整体拒绝。执行失败会尝试回滚，并报告错误。只有收到插件的成功回执才显示完成；旧版插件遇到新操作会拒绝，需更新插件代码并重新运行。

实现依据：[Figma 图片填充](https://developers.figma.com/docs/plugins/api/Paint/)、[文本与字体加载](https://developers.figma.com/docs/plugins/working-with-text/)、[画板自动布局](https://developers.figma.com/docs/plugins/api/FrameNode/)。
