星序 Astrix · 私发试用版

适用电脑：Apple 芯片 Mac（M 系列），macOS 13 或更新版本。
不支持 Intel Mac 或 Windows。安装应用本身不需要 Node、pnpm 或项目源码。

安装
1. 双击 DMG，将 Astrix 拖到 Applications（应用程序）。
2. 退出旧版 Astrix 后再替换，完成后推出安装镜像，从“应用程序”启动。
3. 本包使用临时签名，尚无 Apple Developer ID 签名和公证。首次打开可能被 macOS 拦截。
   确认安装包来自发送者且文件未损坏后，在“系统设置 → 隐私与安全性”中查看是否有“仍要打开”。
   公司管理的电脑可能禁止此操作，需要管理员协助；不能保证所有电脑都能打开。
   不需要关闭系统整体安全检查。损坏或来源不明的安装包请联系发送者重新提供。
   Apple 官方说明：https://support.apple.com/zh-cn/102445

首次使用
1. 应用不包含发送者的账号、登录状态或密钥，每台电脑独立配置。
2. 自由对话和生成任务需要本机可用且已登录的 Agent 后端（默认 Codex CLI，也可使用 Claude Code / Hermes）。
   仅安装 Astrix 不等于已配置 AI 服务；检查应用内 Agent 状态，费用和额度由自己的账号承担。
3. Figma 页面需要登录自己的账号。若“连接 Figma”提示配置 OAuth，请在应用的配置窗口完成配置，
   并确保自己的账号有目标文件权限。Figma 网页登录、OAuth 授权、Bridge 连接是不同步骤。
4. 修改图层需要 Design Studio Bridge 在目标文件中运行。工作区顶部“Bridge 文件”可定位随包插件。
   本地开发插件需在 Figma 官方桌面版通过 manifest.json 导入。内嵌 Figma 页需要已发布的插件；
   尚未具备发布插件时，请在官方 Figma 桌面版打开同一文件并运行导入的 Bridge。
   看到真实选区同步后再发出修改指令，以实际执行回执为准。

当前能力
图片填充/适应与滤镜、资源位预设尺寸、H5 字号/行高/圆角/自动布局间距已接入 Bridge。
H5 调整指 Figma 设计图层属性调整，不是部署一个 H5 网站；资源位尺寸调整不等于自动重新排版。
单人海报支持模板与人物表输入准备；图片生成服务、质量审核及最终成图回填尚未完整接通。

数据与升级
账号配置及工作数据保存在当前 macOS 用户的应用数据目录，替换应用不会自动清空。
更新时退出旧版，拖入新版替换即可；如遇问题可退出新版后换回之前保存的应用。
不要把个人应用数据目录打包给其他人，也不要同时运行多个版本占用本地服务端口 5273。

此版本适合指定人员试用反馈，尚未完成全新电脑、真实账号和真实 Figma 写入的完整验收。
