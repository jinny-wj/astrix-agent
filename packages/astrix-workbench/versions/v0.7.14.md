# Astrix 0.7.14 — 首页真实 Figma 文件目录

日期：2026-11-08。源码标签：`m0/v0.7.14`。

## 变化

- 客户端与网页端首页展示当前 OAuth 账号可读取的真实 Figma 文件名称、缩略图和修改时间，可搜索、刷新及添加官方设计稿链接。
- 已绑定的真实文件可自动成为目录来源；文件信息在服务端通过当前账号向 Figma 重新校验，按账号分别保存链接，无权访问或授权失效时不沿用旧卡片。
- 支持添加团队、项目或文件夹来源，并显式同步。目录权限不足与请求限流返回真实状态，不以空成功或示例文件代替。
- 点击文件先校验访问权限，再复用或创建该账号与文件对应的本地项目，打开原有真实 Figma Design 工作区；显式文件打开优先于之前保存的 Code 模式。
- 网页开发与构建预览共用各自现有的 OAuth 实例；客户端保留原授权交接。顶部「连接 Figma」「API 配置」继续独立显示，模型配置不变。

## 验证

544 项 Node 检查、生成器与画布检查通过，两端最终构建通过。覆盖账号隔离、权限撤回、节点定位、重复打开、网页同步跳转，以及 Vite 开发与预览使用同一 OAuth 实例。验证明细见[本版记录](evidence/v0.7.14.json)。运行资源按本版源码刷新，私有资源暂存版本与脚本哈希一致；两端与共享包版本同步为 0.7.14，依赖未变，两端 pnpm 锁不包含应用自身版本字段，保留原解析。

实机客户端已确认显示真实 OAuth 账号状态，并实际请求用户提供的文件。Figma 元数据接口返回 HTTP 403 `Permission denied`，内容只读接口也返回 `Request denied`；重新完成相同只读授权后结果相同。该文件在官方网页可以只读打开，因此本轮没有把浏览器可见等同于 API 读取成功，也没有展示伪造的文件卡片或缩略图。文件读取与卡片点击的成功路径通过隔离测试验证，**尚未以这份受限文件完成实机成功验收**。

随后使用当前账号另一个已打开、可通过 API 读取的真实文件完成两端实测：名称与更新时间显示成功，网页端的官方缩略图实际加载为 800 像素；客户端卡片打开对应的官方文件地址，网页端同步打开官方文件并绑定本地 Design 工作区。客户端内置的 Figma 编辑器仍需要用户首次正常登录，未复制浏览器凭据。上述成功不代表前述受限文件已解除权限限制。

网页版也完成了隔离未授权状态、官方链接校验与添加入口检查；团队来源的实机枚举仍受下述限制。

## 实际范围

Figma REST 不提供按账号枚举全部文件的接口。基础授权只允许读取已知文件；团队或文件夹枚举需要对应来源、目录只读权限以及支持此能力的 OAuth 应用。本版不自动扩大现有授权。完整说明见 [Figma 文件列表](../docs/Figma文件列表.md)。

OAuth、文件元数据访问、真实编辑器登录与 Plugin Bridge 配对分别反馈；文件卡片打开不等于已经获得图层写入能力。本轮不配置模型，不执行设计稿修改。
