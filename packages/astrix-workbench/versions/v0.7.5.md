# Astrix 0.7.5：双端 Figma OAuth 接入

记录日期：2026-10-25。类型：**source-release（源码发布）**。兼容标签：`m0/v0.7.5`。

默认客户端与网页版的真实 Figma 工作区现在都有独立 OAuth 状态、官方浏览器授权入口和当前文件只读验证。原有设计界面与默认工作台复用同一份 OAuth 协议实现，保留真实画布、Plugin Bridge、原编辑器、终端和扩展；模型配置不变。

## 实现

- 将原有 OAuth 协议归并为可直接运行的 Node ESM，实现仍保留 PKCE、一次性会话交接、加密持久化及官方 REST 只读代理；两端原 TypeScript 入口保留类型包装。
- 默认客户端服务接入 OAuth 路由，客户端与网页版采用独立应用、Cookie 命名和存储实例，避免跨端会话与授权更新冲突。
- 桌面本地交接窗口使用主工作台的会话分区；官方授权页在外部浏览器打开，完成后登录状态返回原工作台。
- 识别 Figma 标准错误响应的 `err` 字段，保留真实访问失败原因；刷新授权使用官方 `/v1/oauth/refresh` 接口，并合并同一会话的并发刷新。
- 前端源码与生成流程同时纳入 OAuth 状态、账号连接、文件读取验证及完成页。没有配置时明确显示待配置，不以 Bridge 在线代替 OAuth 成功。
- 客户端公开配置示例将回调留空以按实际入口推导。发布白名单只新增该公开示例的精确路径，实际本机配置继续禁止提交。
- 临时测试服务显式隔离开发者的 OAuth 设置和运行目录，避免本机已配置账号影响独立测试或触发错误回调。

## 验证边界

[本版证据摘要](evidence/v0.7.5.json)将官方应用创建、账号授权、本机接口测试和 Bridge 在线状态分别记录；操作步骤见 [Figma OAuth 配置](../docs/Figma-OAuth.md)。

- 新增 7 项回归覆盖两端 Cookie 与持久化隔离、一次性回传、只读范围、配置不影响模型、主窗口分区、受控浏览器导航、默认桌面服务真实启动、权限错误与官方并发刷新协议。
- 共享 171 项 Node/画布、18 项宿主策略、3 项扩展策略、3 项导航以及生成器/画布检查通过。网页 44 项测试与构建、客户端构建/类型检查/入口打包通过。
- 6691 个私有运行文件成功暂存，9 个 OAuth 关键文件及内容校验通过；暂存版本在独立临时目录启动成功，未混入本机配置或用户状态。
- 账号持有人已确认组织归属及开发者条款；已在官方控制台创建两个草稿应用，分别登记回调和三项读取权限。本机信息只保存在对应应用的私有配置中。
- 账号持有人另行确认三项只读范围后，两端均实际完成官方 Allow access；客户端授权结果成功交回主工作台，网页版也显示 OAuth 已连接。
- 验证文件的元数据和浅层文件接口被 Figma 返回 403，分别给出 `Permission denied` / `Request denied`。同一账号可在官方网页只读查看，不代表文件或组织已允许 API 读取；本版不记录文件 API 验收成功，也不更改文件共享权限。
- 客户端与网页服务正常重启后，已有 OAuth 授权仍在各自会话中有效；界面实际显示已连接。客户端恢复检查等待首页完整加载后再打开原项目。
- 验证文件的 Bridge 在运行环境切换文件后离线，现有配对保留；不把上一版成功或本版接口测试算作当前真实 Bridge 在线。
- 本轮不配置或调用真实模型，不发送设计稿写入命令。

## 发布

两类资源共六附件单独生成，6641 条资源记录及 325 个当前界面文件独立校验通过；配置、账号、个人插件 ID、项目、截图和原始回执均不发布。27 个旧版本文件、13 条旧索引记录及 14 个既有标签保持原样。

公开源码 Release 不附带运行资源；资源仅保留为受限未发布草稿 `m0-runtime/v0.7.5`。新安装环境仍需自行完成官方授权，OAuth 连接也不会替代内嵌画布的网页登录或增加文件权限。
