# Astrix 0.7.3：单个 Figma 插件连接客户端与网页版

记录日期：2026-10-25。类型：**source-release（源码发布）**。兼容标签：`m0/v0.7.3`。

本版为同一个 Figma 插件增加客户端与网页版的独立连接。两端各自与插件配对，选区按连接上报；来自某个本地服务的命令，其执行回执只回到该服务。连接与凭据不会因切换一端而覆盖另一端。

## 改动与配置边界

- 每端独立保存本地服务地址、配对和会话状态；命令及回执保留来源连接，分别校验目标项目、文件与会话。
- 客户端、网页端与共享包版本同步为 0.7.3，共享 npm 锁同步根版本。两端 pnpm 锁没有应用根版本字段，依赖内容不因版本号变化而改写。
- 当前 README 和运行资源指南使用本版版本与双端连接说明。运行时生成的插件 manifest、个人插件 ID、登录和配对状态不纳入公开源码或资源归档。
- 本轮不修改模型配置、不配置真实模型，也不调用真实模型服务。Bridge 本地连接验证与 AI 对话验证分别处理。

## 验证状态

[本版验证摘要](evidence/v0.7.3.json)将分别记录发布策略、插件与 HTTP 测试场景、官方插件导入、双端登录和实际同时联通。测试节点、VM 或本地 HTTP 回执不能代替官方 Figma 中运行插件的证据。

- 共享完整验证通过：161项Node/画布测试、18项Figma宿主策略、3项市场策略、3项本地导航及生成器/画布综合检查。插件相关23项覆盖双端真实HTTP队列与VM节点场景，其中8项新增检查双端隔离、恢复、回执回源、同ID缓存隔离、单端取消和启动只读；Agent/工作区定向13项也通过。
- 网页44项测试、资源准备与最终构建通过；客户端构建、桌面类型检查和入口生成通过。修正工作区测试只tick一次的时序竞争，让fixture持续模拟插件轮询，没有放宽生产超时。
- 客户端与网页版均已实际运行0.7.3，绑定同一真实设计稿，两端官方Figma画布已可视确认；页面当前以访客只读模式显示，不能据此声称已登录或具有编辑权限。视觉证据仅留本机。
- 已移除插件启动时的文档元数据写入；启动、配对与选区同步的文档写入计数为0。用户指定本轮只读验证，未执行真实文档修改、模型配置或模型调用。
- 真实Bridge仍未在线：本机插件代码已生成，但尚缺Figma正式分配的开发插件ID、官方导入/运行与两端配对。两端实际在线会话均为0，真实选区与读取回执留待这些步骤完成后验收。Figma Desktop已有登录不能替代各端登录或插件导入。
- 发布器定向18项和默认只校验模式通过；23个历史版本文件、11条既有索引和12个既有标签对象保持。资源布局2的六附件、6639条记录及323个当前界面文件已独立校验，未包含个人插件ID、配对/登录状态、用户项目和截图。

0.1.0～0.7.2 的独立版本笔记、证据、既有索引条目和标签保持原样。发布提交标题继续为 `release: Astrix v0.7.3`，公开源码 Release 不附带资源；对应资源按布局 2 生成，仅留在受限草稿 `m0-runtime/v0.7.3`。
