# Astrix 0.7.11 — 保留独立 API 配置按钮

日期：2026-11-08。版本清单中的源码标签为 `m0/v0.7.11`；本页记录本地改动，远程提交、标签及发布状态以实际记录为准。

## 变化

- 客户端与网页端首页保留独立“API 配置”按钮，与“连接 Figma”并列。
- 点击“API 配置”仍打开原有模型连接面板，保留“本机 Codex”和“自定义 API”选择及已有配置行为。
- “连接 Figma”继续进入原 OAuth 流程，授权后端、权限和回调不因按钮命名改变。
- 0.7.10 的本地标签已创建，本轮以 0.7.11 追加记录，不移动旧标签或重写历史。

## 验证

本轮 500 项 Node 测试及生成器、画布检查通过，两端构建通过；首页入口、原 OAuth 和模型配置的 27 项针对性回归通过。实际重启客户端并点击“API 配置”，确认它与“连接 Figma”并列，仍能打开包含本机 Codex、自定义 API 及协议、地址、模型字段的原面板。本次没有保存模型设置、发起推理或新增账号授权。详见[本版验证记录](evidence/v0.7.11.json)。

客户端、网页端及共享包版本同步为 0.7.11，共享 npm 锁同步；两端 pnpm 锁没有应用自身版本字段，依赖未变时保留原有解析。

## 发布与边界

本轮源码、标签与源码 Release 的发布目标为公开仓库 `jinny-wj/astrix-agent`；实际上传、标签及 Release 状态仍须分别核验。本页不宣称已推送或发布，不包含公开安装包发布。

API 配置入口用于模型连接，Figma 入口用于授权；插件配对与设计稿访问权限仍按原流程处理。账号、密钥、会话及本机项目不进入源码。
