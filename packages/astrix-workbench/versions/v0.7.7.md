# Astrix 0.7.7：Claude 与 Gemini 原生 API

记录日期：2026-10-26。类型：**source-release（源码发布）**。兼容标签：`m0/v0.7.7`。

客户端与网页版首页的 **API 设置** 现在可选择 OpenAI 兼容、Claude 原生 Messages、Gemini 原生 GenerateContent。地址和模型名称继续自由填写，支持官方、第三方代理及本机服务。先测试草稿，再保存并决定是否用于对话；使用步骤与协议地址见 [API 配置](../docs/API配置.md)。

## 实现

- Claude 使用 Messages 请求、独立系统提示、原生鉴权、文本与工具内容块；Gemini 使用 GenerateContent / streamGenerateContent、systemInstruction、contents、函数声明及函数结果。
- 普通与流式回复统一返回现有对话契约；工具调用与结果按各自原生格式往返，保留 Gemini 原生函数 ID 及签名。Claude/Gemini 截断的工具响应会报错，不执行未完成调用；请求支持取消、响应大小限制及禁止重定向。
- 恢复的 OpenCode 通过本机网关使用同一适配器，继续执行每角色请求预算。原生元数据只在运行期间按助手轮次与消息指纹保存，不暴露给旧 OpenAI 客户端，也不接受其自带的伪造元数据。
- OpenCode 的原生协议每轮新建请求上下文，并附带已完成的文字历史，避免跨运行重放已经丢失签名的工具记录；原有 OpenAI 会话续用仍保留。
- 旧模型配置缺少 provider 时默认为 OpenAI，读取不重写文件。空 Key 仅保留同协议、同来源的旧值；切换协议清空未保存的输入，后端也阻止跨协议或来源沿用凭据。草稿测试不保存、不启用对话，首页保存不重置高级引擎、工作流或写入开关。
- 原“本地设置”同步三协议；原设计客户端的“AI 模型 API”入口也支持三协议，复用共享调用链、保持加密保存及单轮文字能力限制。

## 验证

[本版证据摘要](evidence/v0.7.7.json)记录源码测试、隔离界面、真实本机应用与资源验收的不同范围。

- 13 项原生协议测试覆盖原生 JSON/SSE、UTF-8 分片、工具往返、原生签名、函数 ID、错误、截断、取消、重定向及响应大小；7 项整合测试覆盖旧配置迁移、跨协议凭据隔离、两类本地 Agent 工具回路、网关转换与预算、重复可见文本对应不同签名。
- 真实恢复的 OpenCode 二进制分别通过 Claude/Gemini 模拟接口读取隔离工作区文件；Gemini 下一轮文字历史及新运行上下文通过。未使用真实模型服务。
- 共享 209 项 Node/画布、18 项宿主策略、3 项扩展策略、3 项导航及生成器/画布检查通过；网页 44 项、客户端 106 项测试通过，两端构建及客户端类型检查/入口打包通过。首页纯表单测试共 9 项，已包含在共享计数内。
- 两套隔离界面分别验证三协议选择、Claude/Gemini 原生草稿、保存与重开、跨协议不沿用 Key、清除、保留高级设置、窄窗口与 Escape 焦点恢复。所有连接请求仅发往本机模拟服务。
- 实际客户端与网页版已以 0.7.7 启动，首页面板与三个选项可见。两端原有模型配置的文件状态及对话模式保持不变，本轮未配置或调用真实模型。
- 客户端暂存 6696 个文件，12 个关键文件与源码及清单哈希一致；隔离暂存服务的两类原生草稿测试通过，未创建模型配置文件，未混入本机状态。
- 六附件通过 67 项独立解包检查，共 6644 条记录；全部 328 个当前 public 文件逐字节一致。31 个旧版本文件、15 条旧版本记录及 16 个既有标签保持原样。

## 发布与边界

公开源码 Release 不附带运行组件；六附件仅保存为受限未发布草稿 `m0-runtime/v0.7.7`，原生运行资源适用 macOS arm64。配置、账号、项目、原始诊断和截图均不发布。

本版原生接口覆盖文字与现有 Agent 工具，不包含图片/音视频生成、Vertex AI 或厂商托管工具。真实厂商兼容性和额度仍需用户填写对应配置后测试。Figma OAuth、文件权限与 Plugin Bridge 配对未改变，既有文件 API 和 Bridge 在线限制不因本功能而视为已解决。
