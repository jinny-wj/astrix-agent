# Astrix 0.7.12 — 首页显示 Figma 授权状态

日期：2026-11-08。版本清单中的源码标签为 `m0/v0.7.12`；本页记录本地改动，远程提交、标签及发布状态以实际记录为准。

## 变化

授权完成后，首页原先缺少状态反馈。本版保留独立“连接 Figma”按钮，从同源服务读取当前 OAuth 会话，并在旁边显示“已连接 · 账号名”、未授权或读取失败状态。

客户端与网页端在首次加载、授权返回、窗口重新聚焦、恢复可见及定期检查时刷新。点击按钮仍使用原有 OAuth 授权入口；“API 配置”按钮及模型连接面板继续独立。

## 验证

本轮 504 项 Node 测试、生成器和画布检查通过，两端构建通过；首页会话反馈、原 OAuth 和模型设置的 31 项针对性检查通过。真实客户端正常重启后，首页已显示此前完成授权的账号状态；没有要求重新授权，也没有新增账号权限。测试覆盖授权返回刷新、未授权、请求失败与恢复、会话过期、隐藏页面暂停、离开取消和旧响应隔离。详见[本版验证记录](evidence/v0.7.12.json)；源码不保存真实用户身份或会话数据。

客户端、网页端及共享包版本同步为 0.7.12，共享 npm 锁同步；两端 pnpm 锁没有应用自身版本字段，依赖未变时保留原有解析。

## 边界与发布

首页显示的是本端 OAuth 会话状态，不代表已打开设计稿、已获得目标文件权限、已完成 Plugin Bridge 配对或已修改图层。授权后端、权限、回调和既有配对流程保持原有职责。

本版 GitHub 上传与发布等待本次目标确认，未宣称已推送、打标签或创建 Release。旧版记录和标签不改动；账号信息、密钥及个人状态不进入源码。
