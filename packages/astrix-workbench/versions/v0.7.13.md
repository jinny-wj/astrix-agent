# Astrix 0.7.13 — 清理首页本地 Figma 占位

日期：2026-11-08。版本清单中的源码标签为 `m0/v0.7.13`；本页记录本地改动，远程提交、标签及发布状态以实际记录为准。

## 变化

- 移除首页“选择项目后连接真实 Figma”“原企业后台列表未接入”等本地占位说明，以及“创建本地项目”“选择已有项目”“打开真实 Figma 工作区”三个引导按钮。
- 前端生成逻辑在该占位分支输出空注释，清理运行时仅服务于这三个按钮的点击处理。
- 顶部独立“连接 Figma”“API 配置”按钮及已有授权状态继续显示，其他错误反馈保留原逻辑。

## 验证

本轮 503 项 Node 测试、生成器和画布检查通过，两端构建通过。既有首页检查已更新，验证占位不再渲染、其他网络和 SSO 错误仍保留；已删除失去入口的点击用例。现有静态资源完成迁移、语法检查及二次刷新幂等验证，真实客户端重启后确认占位文案和三个动作消失，顶部账号已连接状态与 API 配置仍在。详见[本版验证记录](evidence/v0.7.13.json)。

客户端、网页端及共享包版本同步为 0.7.13，共享 npm 锁同步；两端 pnpm 锁没有应用自身版本字段，依赖未变时保留原有解析。

## 边界与发布

本次清理限定于首页本地占位区域及其专用点击处理。Figma OAuth、API 配置和真实连接状态沿用既有链路。
