# Astrix 0.7.8 — 需求澄清与任务续接

日期：2026-11-01。对应源码标签：`m0/v0.7.8`。本页记录实现与本机验证；远程发布状态以 GitHub Release 为准。

## 变化

- 客户端和网页端保存原需求、问题、回答、附件及目标上下文，刷新和服务重启后可恢复。
- 关键输入不足时暂停任务并显示问题；支持卡片提交和普通聊天补充，在原任务中继续。
- 需求预检与执行分开，预检不开放执行工具；格式不合格时停止，不能继续写文件或修改图层。
- 增加新任务、取消、项目与选区隔离、并发保护和请求重试去重。
- 同时覆盖默认工作台和保留的设计界面，未选择或配置模型时显示真实的待运行状态。

## 验证

测试使用临时工作区、模拟运行时和本机接口；具体结果见 [验证记录](evidence/v0.7.8.json)。两端现有依赖未变，应用锁文件保留；客户端、网页端和共享包版本同步为 0.7.8。

## 边界

本次未配置或调用真实模型，未向用户的真实 Figma 文件发送写入命令。问题识别的真实模型质量仍需配置模型后验证；模拟验收覆盖的是暂停、续接、上下文传递和执行控制链路。执行中断不等于自动撤销已发生的工具操作。

会话保存在各端本机私有数据目录，账号、附件原件及会话记录不进入源码发布。历史版本记录和标签保持原样。使用说明见 [需求澄清与续接](../docs/需求澄清与续接.md)。
