# Astrix 0.7.9 — 本机 Codex 与自定义 API

日期：2026-11-07。版本清单中的源码标签为 `m0/v0.7.9`；本页记录本地实现，上传和发布状态以实际远程记录为准。

## 变化

- 客户端与网页端默认首页统一增加“模型连接”，可选本机 Codex 或自定义 API。
- 本机 Codex 使用已通过 ChatGPT 账号登录的 CLI，不要求填写 API Key；模型留空时只沿用本机 Codex 已配置的模型标识，未配置时使用 CLI 默认；也可单独指定模型。
- 安装与登录检测不调用模型；显式草稿测试与实际任务才发起推理。测试不保存配置，保存不发起推理。
- 切到 Codex 保留 API 协议、来源、模型和密钥，保留执行引擎、工作流及写权限。失败时不静默切换到 API。
- 复用已有需求澄清、原任务续接、Agent Loop 和受限工具分发。原设计界面继续提供后端选择，补齐两端的显式 API 配置入口。

## 验证

已确认本机 CLI 安装及 ChatGPT 登录状态可用；该状态检查未发起推理。首页设置的 17 项隔离测试通过，覆盖 API 配置兼容、Codex 请求字段、状态检查与推理分离、关闭取消和重复点击保护。

共享测试 250 项、原生宿主策略 18 项、扩展市场策略 3 项、本地导航策略 3 项，以及生成器和画布脚本通过。客户端 138 项与网页端 77 项测试通过，两端构建及客户端类型检查通过。隔离浏览器验证已确认两端连接选项、ChatGPT 状态和切换时的 API 草稿保留，未填写真实 API Key，也未修改真实用户配置。

真实最小调用已进入 CLI，但默认模型不可用，仍在定位；不能将状态检查或模拟验收写成真实推理成功。具体已完成和待确认项见[验证记录](evidence/v0.7.9.json)。三份包版本和共享 npm 锁同步到 0.7.9；两端 pnpm 锁不记录应用自身版本，依赖未变，保留原有依赖解析。

## 边界

- 原生 CLI 路径只传递文字上下文，不直接发送二进制附件，也不代表图片生成、图像理解或生成类技能已配置。
- 登录可用不等于模型、网络或额度始终可用。安装、登录及额度由本地服务所在机器和账号决定。
- Figma 登录、OAuth 文件读取、插件配对与写权限保持独立；本轮不以模拟结果替代真实设计稿写入验证。
- 不在源码或资源包中分发登录状态、API 密钥、用户项目或会话。执行取消不会撤销已经完成的外部操作。
