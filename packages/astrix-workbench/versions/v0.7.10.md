# Astrix 0.7.10 — 首页 Figma 授权入口

日期：2026-11-08。版本清单中的源码标签为 `m0/v0.7.10`；本页记录本地改动，远程提交、标签及发布状态以实际记录为准。

## 变化

- 客户端与网页端首页顶部恢复独立“连接 Figma”按钮，与“模型连接”和 Design / Code 入口并列，避免遮挡原有入口。
- 点击沿用现有 `/api/auth/figma/start` 授权入口及 `returnTo=/figma-oauth-complete.html`。客户端使用 `handoff=1`，网页版使用 `direct=1`。
- 不更换 OAuth 后端、权限、回调或授权状态逻辑；Figma 授权与模型连接、Plugin Bridge 配对仍分别处理。

## 验证

本轮共 500 项 Node 测试通过，另通过生成器与画布检查；两端构建通过。最终布局调整后，Figma 顶部入口、现有 OAuth 与模型设置的 27 项针对性回归通过。浏览器验证了宽屏与 390px 窗口的按钮布局、独立模型弹窗，以及实际进入 Figma 官方登录流程；运行中的客户端已刷新并观察到恢复的按钮。真实服务返回原有 302 OAuth 跳转、PKCE S256、4317 客户端回调及三项只读权限。本次未在官方页面确认授权，也未读写设计文件。详见[本版验证记录](evidence/v0.7.10.json)。

客户端、网页端及共享包版本同步为 0.7.10，共享 npm 锁文件同步；两端 pnpm 锁没有应用自身版本字段，依赖未变时保留原有解析。

## 边界

首页按钮只恢复现有授权入口，不自动授予新权限。账号授权可用不表示任意文件可读，也不等于插件已配对或有权修改图层。历史版本记录与标签保持原样；本页不宣称已上传或发布。
