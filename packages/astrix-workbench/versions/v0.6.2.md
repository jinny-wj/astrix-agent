# Astrix 0.6.2：统一产品名称

记录日期：2026-10-24。类型：**source-release（源码发布）**。兼容标签：`m0/v0.6.2`。

产品显示名称统一为 **Astrix**，覆盖桌面应用与主窗口、工作台、设置、项目、技能、Figma 工作区和 Plugin Bridge。使用现有 Astrix 标识与桌面图标；启动入口为 `启动Astrix.command`。后续源码 Release 的标题也使用 Astrix。

原有项目、模型配置、Figma 登录和配对继续使用原存储位置及内部协议。`m0-local/` 目录、`m0/` 标签、资源归档文件名和 M0Schema 格式名保留兼容；历史版本与恢复证据不改写。这次更新不增加新的 Figma 云端写入或模型调用。

公开 Release 提供对应源码与说明；生成前端和恢复组件通过受限草稿 `m0-runtime/v0.6.2` 分发。准备步骤见[运行资源说明](../docs/GitHub运行包.md)。它仍是基于恢复构建的本地整合，不能保证与原软件全部功能相同。

验证结果见[本版验收摘要](evidence/v0.6.2.json)。完整记录见[版本总表](index.json)与[变更记录](../CHANGELOG.md)。
