# Astrix 0.7.0：工作台实际拆入客户端与网页端

记录日期：2026-10-25。类型：**source-release（源码发布）**。兼容标签：`m0/v0.7.0`。

本版将此前独立工作台的实现实际放入原有客户端和网页端，并把共用路径、测试与版本记录集中到共享包。共享目录不再提供第三套应用入口。

## 源码与接入

- 浏览器界面、本地服务、项目和会话、Agent、多 Agent、代码生成、保留画布及 Plugin Bridge 位于 `网页端/workbench/`。
- Electron、原编辑器、终端/扩展和隔离工具位于 `客户端/workbench/`，由客户端真实启动和打包流程使用。
- 客户端默认直接进入工作台，`desktop:legacy` 保留原设计界面；网页版的默认 `/` 进入工作台，`/design.html` 保留原 React 界面。开发和构建后预览都连接真实本地后端。
- `packages/astrix-workbench/` 只保存共享配置、测试、文档、版本和发布工具。原 `m0-local/` 可执行源码移除，ignored 用户数据不删除。
- [源码迁移映射](../docs/源码迁移映射.json)逐文件记录旧路径与新位置；历史版本笔记和已有标签保持原内容。

桌面服务通过产品、版本和实例 ID 校验连接，默认端口冲突时使用空闲端口。原编辑器使用短的临时通信路径，并规范化符号链接状态目录，避免目录迁移后出现终端通信失败或文件误拦截。打包应用的项目、登录、编辑器状态与诊断写入用户数据目录，资源目录只用于读取。

## 资源与发布

资源包升级为 **布局 2**，解压到仓库根后分别落到网页端的 `public/`、派生生成器和额外资源，以及客户端的桌面图标。清单包含双端相对路径、版本、字节数和 SHA-256；不再创建旧 `m0-local/` 资源根。原生恢复包仍解压为仓库根的 `M0-AI-recovered/`。

源码发布只允许明确的双端实现、入口接线、共享包及必要配置变更；旧源码路径只可删除，不能把残留用户状态重新加入。公开 `m0/v0.7.0` 仅含源码与文档，运行资源始终留在受限草稿 `m0-runtime/v0.7.0`。

## 验证与边界

[本版验证记录](evidence/v0.7.0.json)包含本次运行的结果：

- 共享 Node/画布检查 151 项、宿主策略 18 项、市场策略 3 项、导航检查 3 项通过，原生成器与保留画布综合检查通过；其中发布范围定向检查 18 项通过。
- 客户端测试 102 项通过，实际原编辑器、PTY/扩展和 Open VSX 市场验收共 42 项通过；arm64 应用构建、资源清单、签名与实际 ASAR 入口验收通过。
- 最终应用复制到独立目录、从空工作目录启动后，首页冒烟检查、包内编辑器/PTY/VSIX 验收 12 项及原设计模式验收 7 项通过；运行组件来自应用自身资源，符号链接状态目录也可使用，退出后测试 helper 正常关闭。
- 网页端测试 39 项、工作台测试 27 项及构建通过；真实 dev/preview 服务验证了默认入口、原设计入口、跨重启历史、文件预览、模型流取消、HMR 和 WebSocket。
- 两个实际资源归档在隔离目录恢复，全部 6,639 条清单记录的内容、权限与链接通过校验；还原的网页服务无需安装依赖即可启动，首页及 21 项静态资源正常，OpenCode、LangGraph 和 callback 实跑通过。

验证日志仅保存在本地，公开记录只包含结果、摘要与 SHA-256，不包含账号、项目、密钥或原始诊断。旧版本的测试次数不计作本次新验收。

浏览器没有 Electron 的 Node/preload 权限，不能把桌面原编辑器与本机终端能力宣称为普通浏览器天然具备。真实 Figma 的云端读写、协作与外部模型仍受正常登录、插件、账户和配置约束。本次源码拆分不代表新增这些外部端到端验收。

运行与资源准备见[共享说明](../README.md)和[运行包说明](../docs/GitHub运行包.md)，逐版发布见[发布流程](../docs/版本发布.md)。
