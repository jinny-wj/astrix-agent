# Astrix 0.7.2：双端运行验收与发布名称统一

记录日期：2026-10-25。类型：**source-release（源码发布）**。兼容标签：`m0/v0.7.2`。

客户端与网页版本次均实际运行到 0.7.2。GitHub 文件和目录行显示最新修改该路径的提交标题；本次使用 `release: Astrix v0.7.2`，覆盖客户端、网页端、共享包和根说明等截图所示路径。

## 改动

- 发布器、协作规则与发布指南统一使用 Astrix 提交标题。兼容标签命名空间及全部已有提交、旧版本记录和旧标签保留，不强推改写历史。
- 客户端、网页端与共享包版本同步到 0.7.2，共享锁同步根版本，两端依赖锁内容未变。
- Figma 工作区在未选项目时明确提示创建或选择项目，禁用依赖项目的操作，结束原先错误的初始化失败与永久载入状态；有项目时保留真实 Figma 宿主与 Plugin Bridge 链路。
- Design 首页在本地模式下提供创建项目、选择项目与真实 Figma 工作区入口，替换原企业后台不支持提示；原 SSO 判断及其他错误处理保留。资产页移除失效的企业手册链接。

## 验证

[本版验证摘要](evidence/v0.7.2.json)保存本次运行结果及仅在本机保留的证据摘要。

- 实际客户端窗口标题为 Astrix，服务报告 desktop 0.7.2；原生编辑器 ready/visible、扩展市场列表与扩展面板通过，真实 PTY 执行只读输出命令并显示验收标记，未修改项目文件，无未保存编辑。已有用户配置先备份后保留。
- 实际网页版报告 web 0.7.2，10 个主路由正常。浏览器检查首页、资产、本地设置、多 Agent、原设计页面与 Figma 无项目提示；首页新入口及失效手册移除可见。
- 网页测试 44/44 通过，最终 TypeScript 与 Vite 构建通过。隔离临时数据验证项目、会话、预览、多 Agent 调度/取消和 Bridge 队列/回执；模型使用本地测试服务，Figma 使用测试节点。
- 共享验证通过：153 项 Node/画布测试、18 项 Figma 宿主、3 项扩展市场与3 项本地导航策略，以及生成器与画布集成检查。发布器定向测试18项通过，包含真实生成的 Astrix 提交标题。
- 版本化运行资源按布局 2 重新生成，校验文件哈希、大小、权限与链接；排除用户配置、项目、会话、诊断和备份。21 个历史版本文件及10条既有索引记录逐字节保持，11个既有标签对象不变。

客户端与网页服务保持运行供本机查看。当前真实模型模式仍为 demo；真实模型和多 Agent 生成需配置模型，真实 Figma 操作需官方登录、目标文件权限与 Plugin Bridge 连接。未宣称真实模型调用、真实设计文件写入或云端多人协作的端到端验收。网页版使用浏览器文件编辑与预览，原生编辑器、PTY 和扩展由客户端提供。

源码 Release 不附带运行资源；对应资源仅进入受限草稿 `m0-runtime/v0.7.2`，不发布公开安装包。运行与发布见[共享说明](../README.md)、[运行包说明](../docs/GitHub运行包.md)与[版本发布流程](../docs/版本发布.md)。
