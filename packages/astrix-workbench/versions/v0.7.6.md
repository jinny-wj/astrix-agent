# Astrix 0.7.6：首页 API 设置

记录日期：2026-10-26。类型：**source-release（源码发布）**。兼容标签：`m0/v0.7.6`。

客户端与网页版的默认首页右上角新增 **API 设置**。可自由填写官方、第三方代理或本机服务的地址、模型名称与 API Key，先测试当前填写内容，再保存并选择是否用于后续对话。使用步骤见 [首页 API 配置](../docs/API配置.md)。

## 实现

- 使用现有 OpenAI 兼容 Chat Completions 调用链，取消来源域名与模型名限制；根路径、完整接口路径及合法查询参数统一处理。不同厂商的原生协议仍需兼容转换，不能仅凭来源自由填写就视为已支持所有协议。
- 首页面板提供加载、重试、连接测试、保存和清除密钥；支持键盘关闭与焦点恢复，并适配窄窗口，避免遮挡原 Design/Code 切换。
- 草稿测试只使用当前输入，不写入配置、不切换实际对话模式。保存时仅更新 API 字段，保留已有引擎、工作流及写入权限；旧“本地设置”入口继续可用。
- 密钥不回显、不写入浏览器存储；空输入仅保留同一来源的旧值，切换来源时不会转发旧密钥，显式清除在保存后生效。服务端采用私有权限的原子文件保存，并隐藏测试回执中的密钥。
- 两端配置保持独立；不更改 Figma OAuth、文件权限或 Plugin Bridge 配对。

## 验证

[本版证据摘要](evidence/v0.7.6.json)分别记录自动化、隔离操作流程、实际界面及资源验收。

- 新增 9 项后端配置测试和 6 项前端请求/凭据状态测试。共享 186 项 Node/画布、18 项宿主策略、3 项扩展策略、3 项导航及生成器/画布检查通过；网页 44 项测试与构建、客户端构建/类型检查/入口打包通过。
- 两套隔离配置的界面操作通过：覆盖测试不保存、保存与清除、空 Key 保留、跨来源不转发密钥、保留原引擎/多 Agent/写入权限及 Escape 焦点恢复。连接仅访问本机模拟服务，未使用真实模型账号。
- 390、720、900、1280 四种宽度检查通过。实际客户端与网页版均以 0.7.6 启动，首页入口及配置面板可见；两端仍为演示模式、未保存模型密钥，配置文件状态与执行前一致。
- 客户端暂存 6694 个运行文件，9 个相关前后端文件与源码及清单哈希一致；隔离暂存服务的草稿请求通过，未创建模型配置文件，未混入本机账号或状态。
- 六个资源附件通过 63 项独立校验，共 6644 条记录；全部 328 个当前 public 文件字节一致，包含新增 API 设置资源。29 个旧版本文件、14 条旧版本记录和 15 个既有标签保持原样。

## 发布与边界

公开源码 Release 不附带运行资源；六附件仅保存为受限未发布草稿 `m0-runtime/v0.7.6`，原生资源适用 macOS arm64。配置、账号、项目、截图和原始回执均不发布。

本轮没有替用户配置或调用真实模型，真实厂商端到端兼容性需填写对应服务后测试。此前 Figma 的文件 API 权限与 Bridge 在线限制仍按 0.7.5 记录，不因新增 API 设置而视为已解决。
