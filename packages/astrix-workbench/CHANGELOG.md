# 版本记录

本工程保存了 0.1.0～0.7.0 的阶段记录，当前源码实际分布于 `网页端/workbench/` 与 `客户端/workbench/`，共享记录位于 `packages/astrix-workbench/`。**0.1.0～0.5.0 未保留完整源码快照，只能追溯当时的文档和验证证据；应用源码从 0.6.0 开始保存。** 不能通过检出历史记录标签取得对应旧版软件；生成资源和恢复运行组件单独分发。

历史阶段使用 `m0/history/v0.x.0` 标签，正式源码版本使用 `m0/v0.x.0` 标签。[历史导入映射](docs/历史导入映射.json)保留原始与导入后的引用、提交关系；旧标签不移动。机器可读清单见 [versions/index.json](versions/index.json)，流程见 [版本发布说明](docs/版本发布.md)。以下验证数量为各阶段留下的结果，不代表在当前版本重新运行旧版测试。

## 0.7.0 — 2026-10-25

**源码版本：`m0/v0.7.0`。** [详细版本记录](versions/v0.7.0.md)

- 将原独立工作台的前端、本地服务、生成器、保留画布和 Bridge 源码移入 `网页端/workbench/`。
- 将 Electron、原编辑器、终端/扩展隔离与原生工具移入 `客户端/workbench/`，由客户端实际入口接入。
- 共享目录只保存路径、测试、版本、文档和发布工具；旧 `m0-local/` 不再保留可执行工程，已有本地用户数据不删除。
- 资源归档升级为布局 2，按仓库相对路径恢复到两端；原引擎恢复包仍位于仓库根 `M0-AI-recovered/`。源码公开发布与资源草稿继续分离。
- 旧版本记录和标签保留，新的迁移/接线验证单独记录，不重复计算旧验收结果。

## 0.6.2 — 2026-10-24

**Astrix 品牌更新；源码版本：`m0/v0.6.2`。** [详细版本记录](versions/v0.6.2.md)

- 应用名、窗口标题、工作台、设置、项目、技能和 Figma 插件的产品名称统一为 Astrix。
- 使用已有 Astrix 品牌图与桌面图标，双击入口改为 `启动Astrix.command`，新导出文件和新建图层使用 Astrix 名称。
- 保留已有存储、登录状态、插件配对与历史标签兼容；恢复来源和 M0Schema 格式仍如实标注。
- 后续源码 Release 标题使用 Astrix；内部目录、标签和资源文件名前缀保留兼容，旧版本不重写。

## 0.6.1 — 2026-10-23

**源码版本：`m0/v0.6.1`。** [详细版本记录](versions/v0.6.1.md)

- M0 应用源码和逐版记录合入 `astrix-agent/m0-local/`，保留六个已映射的历史阶段。
- M0 标签与发布使用独立的 `m0/` 命名空间，保留 Astrix 原有预览与最新版本入口。
- 公开 Git 与 `m0/v0.6.1` Release 保存源码和文档；生成前端、生成器、额外资源、图标及恢复运行组件通过受限草稿 `m0-runtime/v0.6.1` 单独提供。
- 更新新克隆路径、资源准备和版本发布说明；UI、真实 Figma、Plugin Bridge、Agent、编辑器与终端功能没有因本次合入而改变。
- 旧私有仓库的发布验证继续作为来源证据保留，不替代本次合入后的验证结果。

## 0.6.0 — 2026-10-23

**源码版本：`m0/v0.6.0`。** [详细版本记录](versions/v0.6.0.md)

- Design 默认打开真实 Figma，通过独立桌面容器保留官方编辑、矢量和云端协作能力。
- 接入配对 Plugin Bridge，传递选区、受控节点修改、导出和实际执行回执。
- 本地助手、多 Agent 与恢复的 OpenCode 共用桥接工具；AI Figma 写入默认关闭。
- 真实 Figma 导出可接入恢复的 KRN 转换器，保留原工作台、代码编辑器、终端和扩展市场。
- 阶段验证记录为 122 项 Node 回归、17 项宿主策略与生命周期检查、16 项独立桌面检查。插件节点操作使用明确的 Plugin API VM 测试场景；尚未用用户账号完成真实云端文件写入验收。

## 0.5.0 — 2026-10-23

**仅历史文档：`m0/history/v0.5.0`；无完整源码快照。** [详细版本记录](versions/v0.5.0.md)

- 阶段验证记录为 95 项 Node 检查、6 项附加策略/导航检查，以及 59 项画布和多窗口界面检查。
