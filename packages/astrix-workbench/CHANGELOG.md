# 版本记录

## 0.7.7（2026-10-26）

- 首页及原设置入口可选择 OpenAI 兼容、Claude 原生 Messages、Gemini 原生 GenerateContent，自定义来源和模型名称。
- 原生 JSON/SSE、工具调用及结果回传共用两端调用链，保留 Gemini 原生签名与函数 ID。恢复引擎通过本地网关连接原生服务，继续执行请求预算。
- 旧配置默认 OpenAI；空 Key 仅同协议且同来源保留，切换协议不沿用原值。草稿测试不保存或启用真实模型。
- 原设计客户端的文字对话入口同样支持三协议，并复用共享适配器。


本工程保存了 0.1.0～0.7.7 的阶段记录，当前源码实际分布于 `网页端/workbench/` 与 `客户端/workbench/`，共享记录位于 `packages/astrix-workbench/`。**0.1.0～0.5.0 未保留完整源码快照，只能追溯当时的文档和验证证据；应用源码从 0.6.0 开始保存。** 不能通过检出历史记录标签取得对应旧版软件；生成资源和恢复运行组件单独分发。

历史阶段使用 `m0/history/v0.x.0` 标签，正式源码版本使用 `m0/v0.x.0` 标签。[历史导入映射](docs/历史导入映射.json)保留原始与导入后的引用、提交关系；旧标签不移动。机器可读清单见 [versions/index.json](versions/index.json)，流程见 [版本发布说明](docs/版本发布.md)。以下验证数量为各阶段留下的结果，不代表在当前版本重新运行旧版测试。
