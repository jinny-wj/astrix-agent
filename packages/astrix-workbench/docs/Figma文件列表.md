# Figma 文件列表

客户端与网页端首页通过各自的 Figma OAuth 会话读取文件，不需要配置模型。

## 使用

1. 点击顶部「连接 Figma」，完成当前端的账号授权。
2. 首页读取已绑定或已添加文件的真实信息。添加官方设计稿链接后，服务会先向 Figma 校验当前账号的访问权限，再保存到该账号的本机目录。
3. 点击真实文件卡片进入 Design，自动绑定或复用对应本地项目。客户端在真实 Figma 容器打开，首次使用需在该编辑器正常登录一次；网页版同步打开官方 Figma 页面与本地工作台。
4. 如需同步团队目录，添加官方团队、项目或文件夹链接，再执行同步。源文件的修改仍需要目标文件内的 Plugin Bridge。

文件名、缩略图和更新时间来自 Figma。没有缩略图时显示文件标识，不生成假预览；无权访问的文件不作为成功卡片显示。两端分别保存目录与账号状态，账号切换后不沿用上一账号的目录。

## 文件范围

基础授权允许读取已知文件的内容和元数据，**不等于可以枚举账号全部文件**。Figma 当前没有个人「全部文件 / 最近文件」REST 枚举接口，也不能仅凭授权自动获得团队 ID。

目录同步使用已提供的团队或文件夹入口。新版目录接口需要 `folders:read`，且受 OAuth 应用类型限制；旧版项目接口的 `projects:read` 已弃用。现有基础授权不会被程序自动扩大。缺少目录权限、文件被撤销访问、授权失效及请求限流会分别返回真实错误，不能当作空目录成功。

授权成功、文件读取成功、Figma 编辑器登录、Plugin Bridge 配对是不同状态。点击打开不表示已经具备图层修改能力。

官方依据：[Figma 目录接口](https://developers.figma.com/docs/rest-api/folders-endpoints/)、[权限范围](https://developers.figma.com/docs/rest-api/scopes/)、[文件接口](https://developers.figma.com/docs/rest-api/file-endpoints/)。
