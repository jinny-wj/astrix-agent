# M0 本地整合 0.4.0

2026-10-23。本版继续使用恢复出的原工作台、KSCode、扩展安装器和 KRN 转换器，扩充本地画布和云端功能的本地替代。启动入口为 `启动M0.command` 或 `npm run desktop`。模型配置沿用既有设置；演示模式不调用模型。

## 设计画布

原 Design 标签直接显示本地设计编辑器。三栏布局提供页面、图层、资源组件、设计属性与浮动绘图工具。支持多页面、多选/框选、对齐/分布、组合、Frame 自动布局、主组件/实例及显式同步、文字排版、本地图片和图层点击跳转。旧 version 1 文档通过校验器迁移到 version 2，保存在原项目的 `canvas.json`；带修订号的保存和恢复共用同一把项目锁，写入采用完整文件原子替换。未指定项目的独立入口会绑定加载出的项目；未登记的目录另用工作区标识检查，目录切换后拒绝误写。

图片仅接受内容匹配的 PNG、JPEG、WebP，单张不超过 512 KB，文档总计不超过 2 MB。支持的 Figma REST JSON 可保留多页与基础自动布局；`.fig` 二进制、完整矢量/布尔运算、变量/高级特效和 Figma 插件运行时没有实现。

“生成原 KRN 代码”继续调用恢复的原转换器。图像素材按照稳定 SHA-256 文件名输出到同目录 `assets/`，实际源码引用与素材字节一致；生成目录已有文件时拒绝覆盖。该输出仍为 KRN / React Native，目标工程需提供对应依赖。

画布的交互与渲染为本地新增实现，不能等同于已离线启动完整原 Figma 引擎。

## 版本、评论、模板与分享

“版本与协作”入口打开项目绑定的本地设计管理页 `/__local/design-cloud?projectId=…`：

- 保存版本快照并浏览、恢复；恢复和套用模板前自动备份当前文档。
- 对整份设计或具体节点评论、标记解决及重新打开；节点移除时评论保留并提示。
- 把当前设计保存为项目模板，再按修订号保护套用。
- 创建内容固定的本机只读链接，后续编辑不改变分享；可以撤销链接。
- 导出包含多页 SVG 或可点击原型的独立 HTML，在服务关闭后仍可离线查看。

本地管理数据位于 `.local-data/design-cloud/`，按项目及实际目录隔离，不读取原账号或云凭据。版本、评论和模板只保存在这台电脑；链接保持 `127.0.0.1`，要交给他人可下载 HTML 文件。没有实现多人实时编辑、原 Figma 账号同步、企业设计资产与企业发布。

## 本地原型

在图层属性中设置点击跳转到目标 Frame，然后使用“演示”。演示可跨页面切换画板、返回、重新开始和显示热点，也可以导出单 HTML。演示文件只含转义后的 SVG、图片数据和本地导航脚本，禁止联网及调用本机 API。版本分享也可选择原型模式；动画、悬停事件、复杂状态与 Figma 智能动画未实现。

## 扩展市场

Code 工具栏的“扩展市场”打开原 KSCode 扩展面板，默认使用 Open VSX。搜索、详情/README、扩展下载、版本升级、主题应用和卸载均由原扩展服务完成；扩展存放在本工程独立的 editor profile 中。安装本地 VSIX 的入口保留。

联网范围只在原编辑器市场请求层开放公开 Open VSX 与其官方资源域；扩展宿主和语言进程不会因此获得任意联网能力。原主界面的旧服务隔离继续生效。扩展能否完整运行还取决于 VS Code 引擎版本、平台、额外二进制及所需服务；Open VSX 的内容与 Microsoft 市场不同。网络不可用时显示实际错误，可继续从本地 VSIX 安装。

详细接入与官方来源见 `desktop-runtime.md`。本版没有接入 Microsoft 受限市场或模拟其授权。

## 检查与代码入口

`npm test` 已通过 48 项 Node 集成检查、3 项市场策略检查、3 项桌面导航事件检查，以及原插件转换回归与画布模型检查。完整日志在 `diagnostics/integration-tests-0.4.0.log`。界面脚本分别在隔离数据、独立 profile 中验证，不修改用户原有项目。

- `diagnostics/design-prototype-ui.json`：真实点击跨页跳转、返回、热点与离线 HTML；导出后无外部请求。
- `diagnostics/native-editor-marketplace.json`：公开市场实际搜索、详情、下载、升级、主题生效和卸载。
- `diagnostics/canvas-ui-verification.json`：画布编辑和原 Design 入口。
- `diagnostics/canvas-v2-ui-verification.json`：新增画布控件、组件、图片、内嵌原型、版本恢复联动及项目绑定，共 13 组界面检查；截图为 `canvas-v2-ui.png`。
- `diagnostics/canvas-workspace-scope.json`：未登记目录的工作区标识、切目录拒绝误写、协作与原型作用域检查。
- `diagnostics/design-cloud-ui.json`：保存/恢复与自动备份、节点评论解决、模板应用、冻结分享与撤销、离线 HTML，共 7 项实际界面检查；截图为 `design-cloud-ui.png`。
- `diagnostics/native-editor-integration.json`：原编辑器最终 18 项回归全部通过，包含跨页导航、切项目、即时关闭保存及非活动分栏保存。之前失败与复核过程保留在 `native-editor-regression-history.md`。

桌面导航改为等待目标主页面真正提交并完成加载，修复 `loadURL` 提前返回后过早撤销离页标志的竞态。原编辑器的保存也扩展到所有分栏，避免退出或切项目时漏掉非活动分栏。

最终运行核对保存在 `diagnostics/release-0.4.0.json`：桌面服务为 0.4.0、演示模式，原“本地体验项目”和 1 个会话保留，运行画布四个文件与源码逐字节一致；客户端错误和未处理请求均为 0。版本协作页面及项目状态接口可正常访问。

主要代码为 `canvas/`、`server/canvas.mjs`、`server/design-cloud*.mjs`、`server/design-cloud-client.js`、`server/design-prototype.mjs` 和原编辑器市场适配层。原恢复包与原安装应用均保持原样。
