# 本地整合 0.5.0

本版在恢复的原工作台、原编辑器与原 KRN 插件上，新增本地高级矢量编辑和实时操作协作。原恢复证据与已安装 M0 AI 保持独立；新增画布和协作层不是完整 Figma 引擎或原云服务源码。

## 操作入口

双击项目根目录的 `启动M0.command`，进入项目的 **Design**。

- **P**：钢笔点击添加锚点，拖动新点创建贝塞尔控制柄，Enter 完成路径。
- **Enter / 双击图层 / 编辑节点**：拖动锚点与控制柄，插入中点、删除点、平滑/尖角、开合路径。
- 右侧 **Vector**：联集、减去、交集、排除和拼合。布尔运算采用本地固定版本 Paper.js，按实际曲线路径计算，不以包围盒替代。
- 属性面板：旋转、水平/垂直翻转、线性渐变及颜色/角度；变换后的拖动、缩放、路径编辑按 SVG 坐标矩阵换算。
- 文件：导入安全 SVG 子集、包含路径几何的 Figma REST JSON；导出 SVG、M0Schema 和完整可编辑画布 JSON。
- **生成原 KRN 代码**：通过原转换器生成代码，矢量/渐变形状同时生成实际 SVG 素材；文件仍写入项目内的新目录。

顶部 **实时协作 → 开始实时协作** 开启当前项目房间。**打开协作窗口** 在桌面版建立独立窗口；也可生成编辑或只读邀请，在另一浏览器打开。每个成员独立选择页面和视口，显示同伴光标、图层选区、加入与离开状态。

跨电脑使用时，主持人先点击 **开启局域网**，然后生成新的邀请，复制带局域网地址的链接。默认仅本机；局域网是单独的 HTTP 入口，只提供画布静态资源和邀请授权的协作接口，不提供主应用文件、模型和管理 API。邀请应在可信网络内分享，当前没有公网中继或 TLS。

## 保存与协作行为

项目 `canvas.json` 继续原子保存。协作按稳定节点 ID 和属性修改合并，不提交整份旧文档覆盖共享内容；同页面独立新增图层可同时保留。相同属性或不兼容结构被其他人修改时，保留本地草稿并暂停写入，可导出备份或明确采用共享版本。

协作撤销与重做仅针对本人操作；进入与退出协作会清空之前的整份快照历史。远端更新在输入草稿或拖动期间延后应用，避免重绘丢失正在编辑的页名。加入期间暂停编辑，防止加入快照覆盖新改动。

断线后保留待同步操作，恢复有效会话时通过操作回执排除已保存的修改。会话失效时尝试用有效邀请重新加入；服务重启使用新房间 epoch 接受从零开始的事件序号，旧响应不会回退新状态。原会话确认记录在服务重启后不保留，无法证明的同字段变化仍按冲突处理并保留草稿。撤销或过期邀请会停止已有连接。

邀请仅持久化令牌哈希、角色、项目、有效期和撤销状态；在线会话与事件历史不落盘。局域网默认关闭。原账号和登录配置不参与本地协作。

## 验证与来源

运行 `npm test` 验证模型、HTTP、文件隔离、协作与工作流；`npm run test:canvas-ui` 在临时服务依次验收原画布、增强画布和矢量交互；`npm run test:collaboration-ui` 验收真实多窗口协作与实际桌面邀请窗口。所有 GUI 测试按顺序运行，使用独立测试数据，renderer sandbox 开启。

测试报告保存在 `diagnostics/integration-tests-0.5.0.log`、`canvas-ui-verification.json`、`canvas-v2-ui-verification.json`、`canvas-vector-ui-verification.json`、`canvas-collaboration-ui.json` 和 `canvas-desktop-windows.json`。对应截图为 `canvas-vector-ui.png`、`canvas-collaboration-ui.png`。版本运行检查见 `release-0.5.0.json`。

几何库的 MIT 许可证、官方来源和文件 SHA 位于 `canvas/vendor/paper-0.12.18/`。数据字段、辅助 API、SVG 子集、Figma 几何和 KRN 资产边界见 [矢量说明](../../../网页端/workbench/canvas/vector-guide.md)，协作协议见 [实时协作说明](本地实时协作.md)。

## 仍有边界

未取得完整原 Figma WASM/云端服务、`.fig` 二进制协议、完整矢量网络、约束/效果、字体服务、变量与云组件库。Auto Layout、组件同步、原型等仍有此前记录的本地实现范围。当前协作为事务与属性比较机制，未声称实现完整 Figma CRDT 或逐字文本协同。

KRN 目标工程需要支持 SVG 图片资源。原转换器忽略普通图层 transform，因此矢量叶子的变换烘入素材；无法可靠保持的旋转文字/图片或带子图层容器会明确拒绝 KRN 转换，并可继续导出 SVG。默认模型仍为界面演示模式。
