# 本机 Codex 与自定义 API

客户端和网页版默认工作台的首页右上角，均可打开 **模型连接**。两种方式由用户明确选择：本机 Codex 使用已登录 ChatGPT 账号的 Codex 额度；自定义 API 使用指定服务的鉴权与计费。两端独立保存设置。

## 使用本机 Codex

1. 确保运行 Astrix 本地服务的电脑已安装 Codex CLI，启动应用的进程可以找到 `codex` 命令。
2. 如尚未登录，在这台电脑的终端执行 `codex login`，自行完成 ChatGPT 登录；已有 API Key 登录不能当作 ChatGPT 账号额度使用。
3. 打开首页 **模型连接 → 本机 Codex**，点击 **检测状态**。检测只查询 CLI 状态，不向模型发送任务，不消费推理额度。
4. **Codex 模型**留空沿用本机 Codex 已配置的模型；未配置时使用 CLI 默认。也可填写账号支持的模型名称。应用只读取模型名称，不沿用其余用户配置或 API 路由。
5. 保存后回到任务输入框。需要先试用时，可明确点击 **测试 Codex**；测试会发送一次简短模型请求并使用少量账号额度，测试不会保存草稿或切换已保存设置。

保存连接方式不会安装 CLI、自动登录或发起推理。是否能够执行仍取决于账号支持的模型、额度、网络和 CLI 状态。额度不是新增赠送额度，Astrix 也不会绕过账号限制。

## 继续使用自定义 API

选择 **自定义 API**，按服务提供的接口选择 OpenAI 兼容、Claude 原生或 Gemini 原生协议，再填写自由地址、模型和 API Key。支持官方、第三方和本机服务，详见 [API 配置](API配置.md)。

切到本机 Codex 只保存连接方式和独立的 Codex 模型名，不清除已有 API 地址、协议、模型或密钥。切回 API 后可继续使用原配置；修改 API 来源或协议时遵守原有密钥保留规则。登录、额度或执行失败不会自动切换到另一种连接，用户须自行选择。

## 两端与原设计界面

| 入口 | 配置位置 |
| --- | --- |
| macOS 默认工作台 | 首页“模型连接”；使用客户端本地服务所在电脑的 CLI |
| 网页版默认工作台 | 首页“模型连接”；使用网页本地服务所在电脑的 CLI |
| 原设计客户端 | 保留 Codex 后端选择及“AI 模型 API”配置入口 |
| 原设计网页界面 | 保留 Codex 后端选择；API 入口打开同源 `/__local/settings` |

网页版是浏览器连接本地服务的形态。浏览器不会直接读取电脑上的 Codex 登录，也不会调用另一台访问者电脑的 CLI；如果以后将服务部署到其他机器，CLI 安装与登录属于服务所在机器。

## 任务、工具与 Figma

本机 Codex 使用现有任务链路：接收文字需求与历史上下文，返回文字或结构化工具请求；Astrix 继续执行受限工具、回传结果，并保留需求澄清与续接。切换连接不会放宽文件写入或 Figma 写入权限，也不会改变已有执行引擎和工作流设置。

当前 CLI 路径传递**文字上下文**，不直接发送图片、音频或视频附件进行理解，也不等于图片生成服务。Figma OAuth、文件读取、Plugin Bridge 配对与执行回执仍需分别检查；只有真实插件回执能证明图层修改成功。

## 状态异常时

| 提示 | 处理方式 |
| --- | --- |
| 未安装或找不到 CLI | 检查 CLI 安装和应用可见的命令路径，必要时重新启动 Astrix |
| 未登录或登录方式不是 ChatGPT | 终端运行 `codex login`，自行完成 ChatGPT 登录后重新检测 |
| 账号额度、网络或模型不可用 | 按实际错误处理，或主动切换到自定义 API；应用不会代为切换 |
| 状态可用，但任务失败 | 状态检测只检查安装与登录；在明确测试或任务中检查真实模型返回 |

关闭设置面板会取消未完成的检测或测试。取消不能撤回已经由模型服务接收的请求，也不保证退回已用额度。

应用只向设置界面返回安装、登录方式和可用状态，不返回 CLI 登录凭据。账号状态、API 密钥、个人任务与模型设置只留本机，不进入源码或资源包。
