# 资源位延展

把已有 KV / 主视觉重排到多个投放规格，保持品牌、主色和标题层级，批量导出。

## 默认规格

| 名称 | 尺寸 | 输出 |
|---|---|---|
| 热门活动-弹窗 | 840×1120 | ≤300kb png/jpg |
| 直播封面 | 720×1280 | png/jpg，体积不限 |
| 直播广场 banner | 584×160 | ≤300kb png/jpg |

用户点名其他尺寸时，用用户清单覆盖默认规格。

## 执行顺序

1. 确认源 KV（Figma 节点、主视觉图或上一轮成品）。
2. 确认目标规格；没说就用上表三套。
3. 每个规格出 2–3 个方案：构图裁切不同，主色/标题层级不变。
4. 检查：Logo 不变形、关键文案不裁切、安全区、体积限制。
5. 导出分层可编辑结果；不要假装已经写回业务 Figma 原文件。

## 排版规则

- 优先重排，不重绘。主体、标题、贴纸按画幅响应式落位。
- 横转竖：保人脸和主标题，弱化装饰。
- 竖转横：主标题左或中，人物可半身裁切。
- 超宽 banner：标题 + 主视觉局部，不要堆满装饰。

## 用户可见流程

1. 复述将延展的规格。
2. 每个规格给出方案要点（构图 / 主色 / 标题层级 / 导出注意）。
3. 生成缩略预览，标出建议采用的方案。
4. 下一步：导出、改文案、或送去战报/美化。
