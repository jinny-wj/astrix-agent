# 本地生活物料设计规范

## P0 · 高危区域保护（优先级最高）

**任何情况下不可修改**的高危区域：
- 品牌 Logo
- 底部品牌栏上的色块（橙色、蓝色、黄色色块）—— 不可修改
- 固定 UI 框架 / 平台边框元素
- IP 核心造型（圆球形体/无腿/无手指/黄色身体）—— 不可更改

**注意**：
- 搜索框内的文字可以修改（如"快手搜索"→"XX搜索"）
- 底部品牌栏除色块外的其他内容可以修改
- IP 的动作、表情、着装不在 P0 保护范围内，用户可修改，但提示词必须自动追加核心造型保护约束

写进每条 Prompt 的 `[LOCKED]` 块，用文字描述约束 AI 不得触碰这些区域。

## P1 · 风格锁定

**触发条件：** 用户未明确说"改风格 / 换风格 / 改成 XX 风"时，强制执行。

用户大多数时候说"改人物、改商品、改季节、改主题"，真实意图是：**在原有设计风格和系列感不变的前提下，替换内容。** 因此风格必须默认继承，不得因内容替换而漂移。

**锁定维度：**

| 维度 | 示例 |
|------|------|
| 渲染风格 | 粘土3D / 扁平插画 / 写实摄影 / 描边卡通 |
| 光影质感 | 哑光 / 高光 / 柔光 / 赛璐璐 |
| 描边规格 | 有无描边 / 粗细 / 颜色 |
| 色彩系统 | 整体色调 / 饱和度 / 明度倾向 |
| 材质感 | 粘土质感 / 玃璃感 / 金属感 / 布料感 |
| 字体风格 | 手写体 / 衬线 / 粗黑 / 圆润 |
| 版式节奏 | 元素密度 / 留白习惯 / 构图逻辑 |

**季节 / 主题切换时的特别规则：**

当用户说"改成秋天氛围""换成冬日主题"等，AI 容易把渲染风格从粘土3D偷换成写实摄影。此时需额外注入：

> 风格不变，季节/主题通过色彩、道具、环境元素来表达，不得切换渲染方式。

**风格指纹格式**（从素材中提取后写入 Prompt 块2）：

```json
{
  "render_style": "e.g. 3D clay render",
  "lighting": "e.g. soft diffused light, warm highlight on top-left",
  "outline": "e.g. no outline / thick black outline 3px",
  "color_palette": "e.g. warm pastel, high saturation, cream white base",
  "material_feel": "e.g. clay matte texture, slight subsurface scattering",
  "typography_style": "e.g. bold rounded sans-serif",
  "composition_density": "e.g. centered hero, generous negative space"
}
```

## P2 · 尺寸锁定

**触发条件：** 用户未明确说"改尺寸 / 输出 XX 规格"时，强制执行。

输出图与原素材尺寸完全一致，不裁切、不填充、不缩放、不改变比例。

## P4 · 文字渲染强化

**触发条件：** 任何涉及文字 / 数字内容变更。

AI 图生图对文字渲染效果不稳定，容易出现错字、变形、字符残缺。因此：

- **纯图生图方式**：没有模板引擎后处理，所有文字替换必须由 AI 在生成时直接完成
- **强指令策略**：在 Prompt 块 6 中用强语气要求 AI 完整正确地替换文字
- 每处文字替换必须明确指定：原文是什么 → 新内容是什么 → 要求清晰可读
- 不做生成后自检拦截；若用户反馈文字有误（错字/残缺/遗漏），再快速重生成修正

## IP 约束规范

### IP 形象基本定义

流影 IP 是一个**亮黄色圆球生物**，不是任何鸟类或动物。核心特征：
- 身体：光滑圆球形，亮黄色，无羽毛、毛发、鳞片
- 手臂：仅两个圆头短胳膊，**无手指**
- 无腿、无脚、无翅膀、无尾巴
- 脸：两个大圆黑眼睛（内有四角白色高光）+ 简单圆弧笑容
- 头顶：小圆形装饰突起，同色黄色（非耳朵、非鸟嘴、非动物特征）
- 红色背包背带：非强制出现，按需选用

### 三层约束模型

**L1 · 核心造型 — 永远锁死：**
```
✓ 身体为圆球形，亮黄色，表面光滑
✓ 手臂仅为两个无手指的圆头短胳膊
✓ 无腿、无脚、无手指、无爪子、无翅膀
✓ 眼睛：大圆黑眼 + 四角白色高光
✓ 嘴：简单圆弧笑容
✓ 头顶：小圆形装饰突起（非耳朵非鸟嘴）
✗ 绝对禁止：腿 / 脚 / 手指 / 爪子 / 翅膀 / 羽毛 / 鸟嘴
✗ 绝对禁止：将 IP 识别为小鸡、鸭子、任何禽类或动物
```

**L2 · 着装配色 — 可改，有约束：**
```
允许：添加季节性服装、更改背带颜色和样式、添加持有物或漂浮道具
约束：服装不能遮挡脸部、不能暗示有腿、持物时不生成手指、身体保持黄色
```

**L3 · 动作姿态 — 可较自由改：**
```
允许：手臂角度、面部表情、身体朝向与倾斜、体型大小缩放
约束：手臂数量仍为两只、短臂仍无手指、不生成新的身体部位
```

### IP 用户意图拦截规则

当用户要求改变 IP 的核心造型（如"把 IP 换成兔子""给 IP 加腿"），系统应拒绝：

```
IP 的核心造型不可更改（圆球形体 / 无腿 / 无手指为固定设定）。
可以修改 IP 的动作、表情或着装，需要调整哪个方向？
```

### IP Prompt 注入块

**当 IP 区域可能被波及时，以下内容强制追加进 Prompt：**

```
IP 是亮黄色圆球生物，手臂是两个无手指的圆头短胳膊，无腿、无脚、无手指。
禁止：长出腿/脚/手指、变成鸟类或动物。
```

### IP 二次编辑分支

```
用户反馈 IP 有问题
  ├── 核心造型错误（长腿 / 手指 / 变成鸟类） → 强化 L1 约束，原需求重新生成
  ├── 动作或表情不对 → 用户描述期望效果 → 重新生成
  └── 想恢复成原素材中的 IP → 用原素材 IP 区域直接覆盖，不走 AI
```
