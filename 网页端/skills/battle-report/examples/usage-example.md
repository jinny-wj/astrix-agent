## 注意事项

1. **缩略图优先**：必须展示缩略图让用户直观选择，不能用纯文字替代
2. **类型区分**：战报用模板模式（gen_by_template），海报用图生图模式（gen_by_workflow）
3. **ID 范围**：战报 3027-3038（3036除外），海报 0001-0008
4. **原图 CDN**：根据 ID 自动构造原图 URL 展示给用户
5. **修改提示词**：根据模板类型提供分类建议，帮助用户快速表达需求
6. **图片上传**：用户需要替换图片时，先上传到 KCDN 再替换
